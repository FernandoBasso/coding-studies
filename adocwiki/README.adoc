== Ideas

AdocWiki is *not* a documentation website for a single project or tool.
Rather, it is a collection of whatever topic, code, examples, ideas, etc.

The idea is that we have any set of directories and sub-directories, and we simply walk the files to build the “website”.
Maybe, in the future, having a adocwiki.yaml could be considered to allow users to order the sidebar of the website to show things in the order they want, but that is not the initial goal.
